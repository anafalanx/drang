# drang — knowledge bundle

drang is a small, parallel, Perl-inspired scripting language for Windows, implemented in Go. This repository root is an [OKF](https://github.com/GoogleCloudPlatform/knowledge-catalog) knowledge bundle: each document below is a standalone concept with YAML frontmatter, so humans and agents can read and route by it.

- [drang formal reference](REFERENCE.md) — grammar, semantics, and the builtin spec.
- [drang design notes](DESIGN.md) — architecture and the locked decisions.
- [drang roadmap](ROADMAP.md) — what's built, out of scope, and remaining.
- [drang changelog](CHANGELOG.md) — release history.
- [testing drang](TESTING.md) — the local preflight and quality gates.
